# Simplifi Orb — Global Launch Editorial Prompt Pack

**Creative Director brief for a dedicated image model.**  
Do **not** render these in Cursor. Generate in Midjourney / Flux / Ideogram / Firefly / Leonardo, then export to **1240 × 2208** (9:16).

## Campaign thesis

> What if life had a little more clarity?

Every image answers one question:

> How did Orbie make this person's life better today?

**People are always the heroes.** Technology disappears into the experience.  
These are cinematic editorial lifestyle photographs that happen to feature Simplifi Orb — **not** software screenshots, **not** app ads.

## Operator checklist

1. Export / crop every frame to **1240 × 2208**.
2. Logo at **top** — identical placement, scale, spacing across all 8.
3. **If = gold**, **I = electric blue** on every “If I” headline (re-typeset in Figma if the model fails).
4. Orbie: **no face** on every frame; never the loudest element.
5. Reject dark backgrounds, UI screenshots, dashboard energy, stock clichés.
6. Eight different people / places / emotions / compositions — no repeated poses.
7. Ask of every frame: *How did Orbie make this person's life better today?*
8. Soft grade: bright white + gold + electric blue — never purple cyberpunk.
