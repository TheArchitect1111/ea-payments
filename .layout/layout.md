# EA Design Studio — Shared Design Context

## Brand character
Premium, editorial, intelligent, human, confident. Visual polish should feel art-directed rather than templated.

## Default behavior
Do not default to cards, pills, gradients, rounded rectangles, beige minimalism, or oversized type without a compositional reason. The artifact and audience determine the visual system.

## Typography
Use contrast in scale and role. Display type creates hierarchy, serif can add editorial warmth/heritage, sans handles information. Avoid more than three type roles in one artifact.

## Spacing
Use an 8px base rhythm for UI. Posters may use proportional fixed-canvas spacing. Every composition needs intentional negative space, not accidental gaps.

## Shape
Radius is contextual. Premium editorial and sports work often uses square or minimal radius. Portal UI can use restrained radius. Do not make every container a rounded card.

## Imagery
Photography must be relevant to the actual audience and context. Subject requirements in the brief are hard constraints. Images should be integrated into composition, not dropped into generic rectangles.

## Visual systems
### Sports Editorial
High energy; subject-dominant; dramatic crop; layered depth; condensed/bold display type; brush, grain, lines, fields, and motion geometry; facts compact and scannable.

### Heritage Institutional
Archival imagery as atmosphere; ceremonial restraint; strong identity marks; modern typography prevents museum-like stiffness.

### Luxury Editorial
Art-directed imagery, sophisticated whitespace, intentional asymmetry, restrained palette, strong type hierarchy.

### Corporate Modern
Precision, trust, structured information, purposeful charts/graphics, minimal decorative noise.

### Product / Portal
Task-first clarity, strong navigation, information hierarchy, responsive components, obvious next action.

## Medium rules
### Poster / flyer
Fixed canvas. Three-second comprehension. One dominant hero. Primary facts and CTA visible without scrolling.

### Landing page
Narrative scroll. Hero establishes promise. Supporting sections progressively disclose. CTA repeats at decision points.

### Website
Broader story, navigation, credibility, conversion journey, multiple page/section types.

### Portal
Operational utility. Next-best action, clear state, persistent orientation, accessible components.

## QA
Before delivery: visual render, exact target size, no clipping, no broken images, correct subject/identity, correct artifact class, reference-match >=9, brand >=9, visual impact >=9, readability >=9.
