# TB3 Phase 1: storefront and private HQ repair

Baseline: production commit `6b0b83d03f44c176f25bf310af01abd2d4ad81cc`. Isolated branch: `work/tb3-phase1-store-hq-20261103`.

## Implemented
- Both public TB3 store and private HQ use the unchanged approved 14-product catalog and prices.
- Every public product has a direct, item-specific inquiry action; consumers are not shown a non-working Buy button.
- Merchandise inquiry uses the existing tracked booking API, reduced to customer name, email, optional phone and item message. Normal NIL booking keeps its existing fields.
- Unauthenticated HQ visitors are directed to the existing portal sign-in, returning to the private HQ; authenticated unauthorized visitors remain blocked.
- Old Bonfire references removed from public site SEO; public commerce intentionally off.

## Payment remains outside Phase 1
No payment provider keys, bank details, Printful billing, catalog variants, checkout API, production settings, or live charges are changed. The separately developed Stripe/Printful implementation is not merged because it changes approved product listings/prices and assumes a provider decision that the owners have not yet made.
