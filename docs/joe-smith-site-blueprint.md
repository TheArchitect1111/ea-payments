# Joe Smith Basketball Academy — Connected Website Blueprint

## Source
https://www.joesmithbasketballacademy.com/

## Build standard
Source → Capture → Audit → Existing assets/identity → Business/customer journey → Blueprint → Build → Verify.

## Preserve
- Joe Smith as the center of the story.
- Real academy photography and real youth basketball moments from the existing site.
- Classes and workshops.
- Upcoming events.
- Jr. NBA / Jr. WNBA affiliation.
- Existing mission: use basketball to build confidence, discipline, leadership, lifelong skills, better people and future leaders.
- Existing simple navigation language where it remains useful: Home, About, Classes, Events, Contact.

## Friction to remove
- The homepage does not immediately guide a parent from interest to the right class/event/action.
- Classes, events, booking, newsletter, and contact feel like separate destinations rather than one family journey.
- The emotional proof exists in the photography but is not orchestrated into a persuasive story.
- The site has multiple calls to explore without a strong hierarchy around the next best action.
- The business-side follow-up is invisible, so interest can fall into calls, DMs, or manual follow-up.

## Connected family journey
1. Parent arrives from referral, social, event, search, or Joe's reputation.
2. Hero makes the mission and emotional promise clear.
3. Parent chooses the need: Find a Class, See Events, Ask a Question.
4. The site guides the parent to the relevant class/event detail.
5. Interest is captured before the parent disappears.
6. Parent registers/books through the existing booking path.
7. Confirmation and next steps are clear.
8. The same interaction can feed the future Joe business portal/Eva workflow for follow-up and client service.

## Website experience
### Hero
Use a real, warm Joe-with-athletes image from the existing site. Headline should communicate development beyond basketball, using the academy's existing language rather than inventing a new brand persona.

Primary CTA: Find Your Class
Secondary CTA: See Upcoming Events
Quiet tertiary path: Ask Joe's Team

### Guided choice
Immediately after the hero, present three human questions rather than generic feature cards:
- I want to improve my game.
- I want one-on-one coaching.
- I want to see camps, workshops, and events.
Each routes to existing content.

### Joe's mission
Use Joe photography and the existing mission around confidence, discipline, leadership, lifelong skills, better people, and future leaders.

### Jr. NBA / Jr. WNBA trust block
Keep the affiliation prominent and use the source wording without invented stats.

### Practice with us
Retain the real categories visible on the current site, including Team Basketball Drills and One-on-one Coaching, with clearer action labels.

### Upcoming events
Use real event content and imagery when available. Make event discovery a visual section, not a text link island.

### Family next step
Close with one connected action area: choose a class, see an event, or ask a question. Capture email only if the user chooses updates, not as the primary conversion path.

## Visual direction
- Evolve the existing site rather than replace its identity.
- Photography-led, human, warm, kinetic, spacious.
- Avoid generic black/red pro-sports template styling.
- Avoid invented logos, stats, programs, credentials, testimonials, or partnerships.
- Let authentic gym/family/athlete imagery carry emotion.
- Use restrained typography and whitespace so Joe and the athletes remain the visual focus.

## Verification gates
- Joe and real academy life are visually dominant.
- Existing identity is recognizable.
- A parent can identify the next action in under five seconds.
- Classes/events/contact are connected into one journey.
- No invented facts or fake social proof.
- Mobile hierarchy keeps one primary action visible.
- Future portal/Eva handoff is supported without turning the public website into an EA advertisement.
